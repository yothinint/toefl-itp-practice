# TOEFL ITP Practice Test

ข้อสอบจำลอง TOEFL ITP จากเอกสาร *TOEFL ITP — Prepared by Dr. Francis Chan* ทำเป็นเว็บที่ทำได้เหมือนห้องสอบจริง

- **Section 1 Listening** (18 ข้อ): เสียงเล่นต่อเนื่องประมาณ 12 นาที ฟังได้ครั้งเดียว หลังแต่ละคำถามมีเวลาตอบ 12 วินาที
- **Section 2 Structure & Written Expression** (20 ข้อ): จับเวลา 13 นาที
- **Section 3 Reading** (21 ข้อ): จับเวลา 22 นาที แสดงเลขบรรทัดตรงกับที่คำถามอ้างถึง
- หลังทำเสร็จจะเห็นคะแนนแยกตาม Section คะแนนประมาณการแบบ ITP และเฉลยพร้อมคำอธิบายภาษาไทยทุกข้อ ข้อ Listening ฟังซ้ำและดูสคริปต์ได้
- คำตอบบันทึกใน localStorage ถ้าปิดหน้าเว็บกลางคันก็กลับมาทำต่อได้

## เปิดใช้งาน

เปิดผ่าน GitHub Pages หรือรันในเครื่องด้วยคำสั่ง `python3 -m http.server` แล้วเข้า http://localhost:8000
(ถ้าเปิดไฟล์ `index.html` ตรงๆ เสียงอาจเล่นไม่ได้ในบางเบราว์เซอร์)

## แก้ข้อสอบหรือสร้างเสียงใหม่

ข้อมูลทั้งหมดอยู่ใน `tools/exam.json` แก้ไฟล์นี้แล้วรันคำสั่งต่อไปนี้บน Mac:

```bash
python3 tools/build.py
```

สคริปต์ใช้คำสั่ง `say` ของ macOS สร้างเสียงจาก audio script (Narrator = Daniel, Woman = Samantha, Man = Reed)
แล้วใช้ `afconvert` แปลงเป็น `audio/section1.m4a` จากนั้นสร้าง `data.js` พร้อมเวลาของแต่ละข้อ

## หมายเหตุ

- เฉลย Reading มาจาก Answer Key ในเอกสาร ส่วนเฉลย Listening และ Structure เรียบเรียงจาก audio script และหลักไวยากรณ์
- คะแนนประมาณการเทียบเป็นเส้นตรงจากสัดส่วนข้อที่ถูก ใช้ดูแนวโน้มได้ แต่ไม่ใช่ตารางแปลงคะแนนทางการ
